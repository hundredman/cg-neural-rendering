What is Rendering?

Rasterization
3D geometry → 2D pixels
Project 3D triangles onto the screen. For each pixel, check if it's inside a triangle — if yes, shade it using a lighting model.
SpeedVery fast — real-time on GPU
QualityNeeds tricks for shadows & reflections
Used inGames, AR/VR
Ray Tracing
simulate how light physically travels
Shoot rays from the camera. When a ray hits a surface, spawn new rays for shadows, reflections, and refractions.
SpeedSlow — expensive per pixel
QualityPhysically accurate lighting
Used inFilm VFX, offline rendering
