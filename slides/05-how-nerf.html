NeRF · Neural Radiance Fields (2020)

How NeRF renders one pixel
1
Take ~20–100 photos
From different angles, with known camera positions.
2
Train the network
It tries to reproduce each training photo. Repeats until the output matches reality.
3
Render any new angle
Give the trained network a new camera position → it generates the image.
4
Reflections work naturally
The network takes viewing direction as input, so shiny surfaces look correct from every angle.
What the network does position + direction → density + color
