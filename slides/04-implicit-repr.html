Implicit Neural
Encode the scene in a function
The scene is a learned neural network — maps coordinates → properties.
NeRFSDF NetworkOccupancy Net
What does this mean?
A network Fθ is a continuous function. The scene is encoded in the weights — query any point by running the network forward.
General FormFθ(x, y, z) → scene property
NeRFFθ(x, y, z, θ, φ) → (density σ, color RGB)
📐
Like a math function
x² + y² = r² describes a circle — no list of points needed.
🗜️
Like compression
A few MB of weights encodes a scene needing GBs as a voxel grid.
🔍
Infinite resolution
Query at any spatial resolution — no pixelation from grid size.
