Core Concept

What is Neural Rendering?

In one sentence
Instead of building a 3D mesh, we train a neural network to memorize a scene — then ask it to render that scene from any angle.
Key ideas
🧠
The network IS the 3D model
No mesh, no point cloud. The scene is stored inside the neural network's weights.
📸
Train on 2D photos only
Give it ~20–100 photos from known angles. It learns to reproduce them — and fill in the gaps.
🎥
Render from any new viewpoint
Ask the trained network "what does this scene look like from here?" — it generates the image.
